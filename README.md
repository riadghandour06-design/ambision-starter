# Ambision Starter

Do not build a product, landing page, or any content. I only want an empty starter project that I will build myself in my own editor.

Set up exactly this and nothing more:
- A single route at `/` rendering one centred `<h1>` with the text "Ambision". No other text.
- No extra routes, no header, no footer, no nav, no sections, no cards, no forms, no placeholder copy, no demo components.
- Leave the default theme, styling and project structure as they come. Do not add fonts, colour palettes, animations or custom CSS.
- Do not install extra dependencies.

That's the whole task. Do not add anything I have not asked for, and do not suggest or build extra features.

This project was built with [Lovable](https://lovable.dev).
